# Payoo Mobile Bank

Payoo is a mobile banking web application built as a learning project during the Programming Hero Web Development course. It simulates basic mobile banking operations, allowing users to add money, cash out, send money, claim bonuses, and pay bills.

The project focuses on JavaScript, DOM manipulation, event handling, form validation, and building an interactive frontend interface.

## Live Link :
https://sanjanaoney.github.io/payoo-mobile-bank/


## Features

- **Login:** A simple login system using a mobile number and PIN.
- **Add Money:** Add money to the available balance by selecting a bank and entering account details.
- **Cash Out:** Withdraw money from the available balance.
- **Send Money:** Transfer money to another account within the simulation.
- **Get Bonus:** Claim a bonus using a valid coupon code.
- **Pay Bill:** Pay electricity, gas, water, and internet bills.
- **Transaction History:** View completed transactions with their type and time.
- **Balance Updates:** The available balance updates after successful transactions.
- **Form Validation:** Checks for invalid amounts, incorrect PINs, insufficient balance, and invalid account numbers.
- **Responsive Interface:** A mobile banking-inspired interface built using Tailwind CSS and DaisyUI.

## Technologies Used

- HTML5
- Tailwind CSS
- DaisyUI
- JavaScript (ES6)

## Note

This is a frontend learning project developed as part of the Programming Hero Web Development course.

Payoo is a banking simulation and does not process real financial transactions. The login and transaction validation are implemented for demonstration purposes and are not intended for real-world banking security.

Account balances and transaction history are maintained during the current page session and are not stored in a database.
